# Jarvis (etapa 1)

Asistente personal por voz: le hablás, responde en voz alta.

## Arrancar
1. Instalá Node.js 18 o más nuevo.
2. En esta carpeta: `npm install`
3. Copiá `.env.example` como `.env` y pegá tu `ANTHROPIC_API_KEY`.
4. `npm start` y abrí http://localhost:3000 en Chrome.

## Usarlo desde el celular
El micrófono del navegador solo funciona con HTTPS (o localhost). Subí la carpeta a un hosting con HTTPS (Render, Railway, etc.), cargá las variables del `.env` ahí y definí un `ACCESS_CODE` para que nadie más use tu clave.
